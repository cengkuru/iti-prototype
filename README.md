# ITI Website Success Prototype

A click-through prototype of a proposed public-facing layer for the Infrastructure Transparency Index website. Built as a persuasion artifact for review: it shows what the site could feel like to a cold visitor (a donor, government, journalist) who needs to understand the value, trust the evidence, and know what to do next.

**Live preview:** https://cengkuru.github.io/iti-prototype/

Multi-page, self-contained, editorial/data-journalism register on the real ITI brand palette. See `PROTOTYPE-NOTES.md` for what is real, what is illustrative, and the decisions behind it.

> Figures are illustrative and pending publication assurance. Images are generated for the prototype and should be replaced with authentic, rights-cleared CoST photography before any public launch.
